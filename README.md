# 召喚継界クロスバースト (Cross Burst)

ターン制 × 攻撃タイミングの重なり（Chain Sync）で戦う、**依存なしブラウザ RPG プロトタイプ**。
ブレイブフロンティア系の「ゲージを溜めて必殺技、ヒットを重ねて連携」という戦闘の手触りを検証する個人制作。

## ▶ プレイ

**https://rindadan0212-stack.github.io/cross-burst/**

スマホ縦持ち推奨。ブラウザだけで動きます（インストール不要）。

## 操作（スマホ／PC）

| 操作 | 動作 |
|---|---|
| ユニットを **タップ** | 通常攻撃 |
| ユニットを **長押し / 上スワイプ** | ブレイブバースト（ゲージ満タン時） |
| 中央ゲージをタップ | 連携バースト（XBB） |
| 下部のアイテム | 回復薬 / 武神薬 / 護盾薬 / 蘇生薬 |
| 上部 防御 / 自動 / 速度 | 全体防御・オート・速度切替 |

PC では長押しの代わりに **右クリック** または **Shift+クリック** でもバースト。

## 特徴

- **BC × Chain Sync の二重ループ** — 攻撃でゲージを溜めて必殺技、ヒットのタイミングを重ねて追撃ダメージ＋ゲージ加速
- 自前5体＋助っ人1体の **6体編成**、配置順＝攻撃速度＝連携成立率
- 6属性の相性（弱点 ×1.5 / 耐性 ×0.5）、**クリティカル**、状態異常、崩し（Break）
- ユニット育成（進化・レベル・レリック）、クエスト／ミッション、素材交換

戦闘パラメータは [`src/combat_config.js`](src/combat_config.js) に外部化してあり、数値だけで挙動を調整できます。

## ローカルで動かす

```bash
python -m http.server 7342 --bind 127.0.0.1
# → http://127.0.0.1:7342/
```

`index.html` を直接開いても動作します。ビルド不要（vanilla JS / HTML / CSS）。

## 構成

```
index.html            画面構造
src/styles.css        スタイル（スマホ縦持ち前提）
src/combat_config.js  戦闘チューニング値
src/main.js           ゲームロジック
```

本作は戦闘システムの学習・実験を目的とした**個人制作のオリジナル作品**です。
